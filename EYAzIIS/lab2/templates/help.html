Руководство пользователя

Цель системы: автоматический анализ английского текста с извлечением лексем, их нормальных форм (лемм), частей речи и синтаксических ролей. Также система собирает статистику производительности для оценки скорости обработки.

1. Загрузка текста

Перейдите на главную страницу и выберите один из способов:

  • Вставьте текст вручную в поле «Текст».
  • Загрузите файл формата .txt или .rtf.

После нажатия кнопки «Обработать» система:

  • разобьёт текст на слова,
  • проигнорирует пунктуацию, числа, URL, email и спецсимволы,
  • определит лемму, часть речи и синтаксическую роль для каждого слова,
  • сохранит уникальные записи в словарь,
  • запишет в статистику: количество слов и время обработки.

Вы увидите уведомление вида: «Слов: 42, время: 0.152 сек.»

2. Просмотр и фильтрация словаря

На странице «Просмотреть словарь» вы увидите таблицу со всеми записями.

Чтобы найти нужные слова:

  • Введите часть леммы (например, run найдёт run, running, ran),
  • или форму (running),
  • или часть речи (Глагол, Существительное и т.д.),
  • или синтаксическую роль (Именное подлежащее, Прямое дополнение и др.).

Нажмите «Фильтровать» — таблица обновится. Чтобы сбросить фильтр — нажмите «Сбросить».

3. Добавление и редактирование записей

  • Кнопка Добавить запись — создаёт новую запись вручную.
  • В таблице рядом с каждой записью есть кнопка ✏️ — она ведёт на страницу редактирования.
  • Поля «Лемма» и «Форма» обязательны.

4. Удаление записей

Нажмите на значок 🗑️ рядом с записью. Появится подтверждение — подтвердите удаление.

5. Статистика производительности

Перейдите на страницу «Статистика», чтобы увидеть:

  • График зависимости количества слов от времени обработки,
  • Таблицу всех замеров с точным временем и скоростью (слов/сек),
  • Историю всех загрузок текста.

Это позволяет оценить, насколько быстро работает система при разных объёмах текста.

Основные термины

Лексема (lexeme)
Абстрактная единица словаря, объединяющая все формы одного слова. Например, лексема run включает формы: run, runs, ran, running.
Форма слова (word form)
Конкретное написание слова в тексте. Например, в предложении «He is running» форма слова — running.
Лемма (lemma)
Нормальная (словарная) форма слова. Для глаголов — инфинитив (to run → run), для существительных — именительный падеж единственного числа (cats → cat).
Часть речи
Грамматическая категория слова. В системе используются русские названия: Существительное, Глагол, Прилагательное, Наречие, Местоимение, Предлог и др.
Синтаксическая роль
Функция слова в предложении. Примеры:
  • Именное подлежащее — подлежащее
  • Прямое дополнение — объект действия
  • Корень предложения — главный глагол
  • Определение — атрибутивное прилагательное
  • Обстоятельство — наречное модификатор

6. Технические ограничения

  • Анализ выполняется только для английских текстов.
  • Поддерживаются файлы .txt и .rtf.
  • Слова с цифрами, символами или длиннее 31 символа игнорируются.
  • Дубликаты (по комбинации лемма+форма+часть речи+роль) не сохраняются.
  • Статистика хранится локально и не отправляется на серверы.

Возникли проблемы?

Убедитесь, что:

  • текст на английском языке,
  • файл не повреждён,
  • вы заполнили обязательные поля при ручном вводе.
Если ошибка остаётся — обратитесь к разработчику.
