Руководство пользователя корпусного менеджера

Назначение системы: Корпусный менеджер для построения, хранения и лингвистического анализа размеченных текстов естественного языка (английский).

1. О корпусах текстов

Корпус текстов — это большой, представленный в электронном виде, унифицированный, структурированный, размеченный, филологически компетентный массив языковых данных.

Важнейшие свойства корпуса:
  • Репрезентативность — корпус должен объективно представить разнообразие изучаемого явления в речевой практике носителей языка
  • Разметка — приписывание текстам и их компонентам специальных меток (морфологических, синтаксических)
  • Метаданные — библиографическая и типологическая информация о каждом тексте (автор, год, жанр, предметная область)

Внимание! В данной системе слова (лексемы) извлекаются автоматически из текстов. Нельзя добавлять или удалять отдельные слова — они существуют только в контексте исходного текста. Для изменения лексики необходимо редактировать сам текст.

2. Загрузка текста в корпус

Перейдите на главную страницу для добавления нового текста.

Шаг 1: Выберите источник текста
  • Вставка текста — скопируйте и вставьте текст в поле «Текст»
  • Загрузка файла — выберите файл формата .txt, .rtf, .docx или .pdf
Шаг 2: Заполните метаданные (обязательно для корпуса!)

Шаг 3: Обработка

После нажатия кнопки «Обработать и добавить в корпус» система:

  1. Сохранит текст с метаданными в таблицу corpus_texts
  2. Разобьёт текст на слова (токенизация)
  3. Определит для каждого слова:
    • Лемму — нормальную (словарную) форму
    • Форму — конкретное написание в тексте
    • Часть речи — грамматическую категорию
    • Синтаксическую роль — функцию в предложении
    • Частоту — количество вхождений в тексте
  4. Сохранит разметку в таблицу vocabulary
  5. Запишет статистику производительности

Перейдите на страницу «Корпус текстов» для управления документами.

Доступные действия:

4. Поиск и просмотр лексики

Перейдите на страницу «Поиск по лексике» для работы со словарём корпуса.

Фильтрация:

Введите критерии поиска (поддерживается частичное совпадение):

  • Лемма — например, run найдёт все формы этой лексемы
  • Форма — конкретное написание, например running
  • Часть речи — например, Глагол, Существительное
Действия с лексемами:

✏️ Редактирование Изменить часть речи и/или синтаксическую роль. Частота старой записи уменьшится на 1, будет создана новая запись
Конкорданс Конкорданс Показать слово в контексте исходного текста (окружающий текст ±50 символов)
Принцип целостности: Лемма и форма слова не могут быть изменены вручную, так как они извлекаются из исходного текста. Для изменения необходимо редактировать сам текст.

5. Статистика производительности

Перейдите на страницу «Статистика» для анализа работы системы.

Отображаемые данные:
  • График — зависимость количества слов от времени обработки
  • Таблица — история всех загрузок с точными замерами
  • Скорость — количество слов в секунду (слов/сек)
  • Объём корпуса — общее количество текстов и слов

6. Основные термины

Лексема (lexeme)
Абстрактная единица словаря, объединяющая все формы одного слова. Например, лексема run включает формы: run, runs, ran, running.
Форма слова (word form)
Конкретное написание слова в тексте. Например, в предложении «He is running» форма слова — running.
Лемма (lemma)
Нормальная (словарная) форма слова. Для глаголов — инфинитив (to run → run), для существительных — именительный падеж единственного числа (cats → cat).
Часть речи (POS)
Грамматическая категория слова. В системе используются русские названия: Существительное, Глагол, Прилагательное, Наречие, Местоимение, Предлог, Союз и др.
Синтаксическая роль (Dependency)
Функция слова в предложении согласно теории зависимостей. Примеры:
  • Именное подлежащее (nsubj) — подлежащее
  • Прямое дополнение (dobj) — объект действия
  • Корень предложения (root) — главный глагол
  • Определение (amod) — атрибутивное прилагательное
  • Обстоятельство (advmod) — наречный модификатор
Конкорданс
Список вхождений слова в тексте с отображением окружающего контекста. Используется для лингвистического анализа употребления слова.
Метаданные
Информация о тексте, не являющаяся его содержимым: автор, год, жанр, предметная область, источник. Необходима для филологической компетентности корпуса.

7. Технические характеристики

Поддерживаемые форматы:
  • .txt — простой текст (UTF-8)
  • .rtf — Rich Text Format
  • .docx — Microsoft Word (требуется библиотека python-docx)
  • .pdf — PDF-документы (требуется библиотека pdfplumber)
Ограничения:
  • Анализ выполняется только для английских текстов (модель spaCy en_core_web_sm)
  • Слова с цифрами, символами, URL, email игнорируются
  • Длина леммы и формы ограничена 31 символом
  • Пунктуация и пробелы не сохраняются как отдельные токены
Структура хранения данных:
  • corpus_texts — тексты с метаданными
  • vocabulary — лингвистическая разметка (связана с текстами через text_id)
  • parsing_stats — статистика производительности

8. Часто задаваемые вопросы

Это требование целостности корпуса. Слова существуют только в контексте текста. Если нужно добавить слово — добавьте его в исходный текст и обработайте заново.

Старый текст и все его лексемы удаляются (CASCADE). Новый текст обрабатывается заново с полным лингвистическим анализом. Это гарантирует актуальность данных.

Частота старой записи уменьшается на 1. Создаётся новая запись с изменёнными параметрами (частота = 1). Если частота старой была 1 — она удаляется.

Поиск по форме слова точный. Для поиска всех форм используйте поле «Лемма» — там поддерживается частичное совпадение. Конкорданс использует границы слова (\b), поэтому "run" не найдётся внутри "running".

9. Возникли проблемы?

Проверьте следующее:
  • Текст должен быть на английском языке
  • Файл не должен быть повреждён
  • Все обязательные поля метаданных должны быть заполнены
  • Для работы требуется модель spaCy: python -m spacy download en_core_web_sm
  • Для .docx и .pdf нужны дополнительные библиотеки (см. requirements.txt)
