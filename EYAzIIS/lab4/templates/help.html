Руководство пользователя

Цель системы: автоматический семантико-синтаксический анализ английских текстов с построением деревьев зависимостей и определением семантических классов слов.

1. Загрузка текста

На главной странице вы можете:

  • Вставить английский текст вручную в поле «Текст»
  • Загрузить файл формата .txt или .rtf
  • Указать название анализа (необязательно)

2. Просмотр результатов

На странице «Список текстов» отображаются все сохранённые анализы:

  • 👁️ Просмотр — увидеть список предложений
  • ✏️ Редактировать — изменить название анализа
  • 🗑️ Удалить — удалить анализ из базы

3. Семантико-синтаксический анализ предложения

При просмотре анализа нажмите на любое предложение для просмотра:

  • Текст предложения
  • Дерево зависимостей — интерактивная визуализация с цветовой кодировкой семантических классов
  • Структура дерева — иерархическое представление с семантическими метками
  • Таблицу токенов — полная информация о каждом слове
  • Карточки токенов — детальная семантическая информация

4. Семантические классы

Система автоматически определяет семантический класс для каждого слова:

  • ЖИВОТНОЕ — cat, dog, bird
  • ЧЕЛОВЕК — man, woman, he, she
  • ОБЪЕКТ — table, car, book
  • ДЕЙСТВИЕ — run, eat, sleep
  • СВОЙСТВО — big, red, beautiful
  • ОБСТОЯТЕЛЬСТВО — quickly, very, here
  • КОЛИЧЕСТВО — 5, many, few
  • ОТНОШЕНИЕ — in, on, and, but
  • ПУНКТУАЦИЯ — . , ! ?
  • ЛОКАЦИЯ — London, Paris, home
  • ВРЕМЯ — today, now, yesterday
  • ОРГАНИЗАЦИЯ — Google, Microsoft

5. Статистика

Страница «Статистика» показывает:

  • График производительности
  • Количество обработанных слов
  • Время обработки каждого анализа
  • Скорость обработки (слов/сек)

Основные термины

Токен
Отдельное слово или знак препинания в тексте.
Лемма
Нормальная (словарная) форма слова. Например: running → run, cats → cat.
Часть речи (POS tag)
Грамматическая категория слова (существительное, глагол, прилагательное и т.д.).
Синтаксическая роль (Dependency)
Функция слова в предложении:
  • Именное подлежащее — подлежащее
  • Прямое дополнение — объект действия
  • Корень предложения — главный глагол
  • Определение — атрибутивное прилагательное
  • Обстоятельство — наречный модификатор
Семантический класс
Смысловая категория слова, определяющая его значение:
  • ЖИВОТНОЕ — живые существа (кроме людей)
  • ЧЕЛОВЕК — люди, местоимения лиц
  • ОБЪЕКТ — предметы, вещи
  • ДЕЙСТВИЕ — глаголы, процессы
  • СВОЙСТВО — качества, характеристики
Именованная сущность (NER)
Распознанные объекты реального мира:
  • PERSON — имена людей
  • ORG — организации
  • GPE/LOC — географические объекты
  • DATE/TIME — даты и время
Дерево зависимостей
Графическое представление синтаксических связей между словами. Каждое слово связано с родительским словом направленным отношением.
Семантическая похожесть
Числовая мера (от 0 до 1) смысловой близости между словами, вычисляемая на основе векторных представлений.

6. Технические возможности

  • Синтаксический анализ — определение структуры предложения и грамматических связей
  • Семантическая классификация — отнесение слов к смысловым категориям
  • Распознавание именованных сущностей (NER) — автоматическое выявление имён, организаций, локаций
  • Векторная семантика — вычисление семантической похожести между словами
  • Интерактивная визуализация — масштабирование, перетаскивание узлов дерева
  • Определение стоп-слов — маркировка служебных слов

7. Технические ограничения

  • Анализ выполняется только для английских текстов
  • Поддерживаются файлы .txt и .rtf
  • Максимальный размер файла: 16 MB
  • Игнорируются: URL, email, числа, спецсимволы
  • Статистика хранится локально в SQLite
  • Требуется модель spaCy en_core_web_md (с векторами)

Примеры текстов для тестирования

Простой текст:

The cat runs quickly. She loves to play.

С именованными сущностями:

John works at Microsoft in London. He visited Paris last week.

Сложный текст:

The beautiful garden bloomed in spring. Many colorful flowers attracted bees and butterflies. Children played happily near the old fountain.

Возникли проблемы?

Убедитесь, что:

  • Текст на английском языке
  • Файл не повреждён
  • Установлены все зависимости (spacy, flask, etc.)
  • Загружена модель spaCy: python -m spacy download en_core_web_md

Если ошибка остаётся — проверьте консоль на наличие сообщений об ошибках.
